## 🕷️ About the Project

**Spiderweb** is a highly dynamic 2D web-swinging action-platformer that puts you in the shoes of a masked vigilante traversing the neon-lit cityscape. Experience physics-driven swinging, high-speed combat, and seamless parkour as you battle notorious enemies across the skyline!

Developed using modern web technologies and a custom-built 2D physics engine for an authentic pendulum-swinging feel.

## 🚀 Features

- **Physics-Driven Web Swinging**: Real closed-form pendulum formulas ensure stable, realistic, and exhilarating swinging mechanics at any frame rate.
- **Dynamic Action Combat**: fluid combat system with dodges, counter-attacks, and spectacular web-strikes.
- **Epic Boss Battles**: Challenge formidable bosses with multi-phase mechanics (The Enforcer, Thread, Stinger).
- **Responsive UI/UX**: Includes a detailed Mission Tracker, HUD overlay, and accessible Settings.
- **Vibrant Art Style**: Crisp pixel art with glowing neon accents (Teal & Navy Blue) breathing life into the urban jungle.

## 🏗️ Deployment (Vercel)

This project is built to be a standalone, purely static web game that is extremely easy to deploy to [Vercel](https://vercel.com).

### One-Click Deploy
1. Push this repository to GitHub.
2. Sign in to your Vercel Dashboard.
3. Click **Add New** > **Project** and import this GitHub repository.
4. Leave all build settings as default (Framework Preset: `Other`, Build Command: `Empty`, Output Directory: `Empty`).
5. Click **Deploy**.

Vercel will automatically serve the `index.html` file at the root, making your game instantly playable worldwide!

### Local Development

To run the game locally, you can use any standard live server:

```bash
# Using Node.js (http-server)
npx http-server

# Using Python
python3 -m http.server 8000
```
Then visit `http://localhost:8000` or the specified port in your browser.
